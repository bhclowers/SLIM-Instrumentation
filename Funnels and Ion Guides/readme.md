## Ion Funnel and SRIGs
#
Design repository for the Ion Funnels and Stacked Ring Ion Guides (SRIG) used to introduce ions into the SLIM systems at WSU. These boards are designed in KiCad with the layout designed to be modular. This ion guide environment can be extended to accommodate different ion guide diameters and even used to create ion funnels. A SRIG/Funnel Layout tool can be found here: [KiCad Layout Script](https://github.com/bhclowers/Instrument-Design/tree/master/KiCad%20Scripts)
